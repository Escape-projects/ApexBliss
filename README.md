# 💻 ApexBliss

**Система управления компьютерным клубом на C# 10 с Dapper, DI и Repository Pattern**

---

## 📌 О проекте

**ApexBliss** — это консольное приложение для управления компьютерным клубом. Проект демонстрирует современный подход к разработке на C# с использованием актуальных технологий и паттернов.

**Ключевые архитектурные решения:**
- **Dependency Injection** — все зависимости передаются через конструктор.
- **Repository Pattern** — работа с БД вынесена в отдельные репозитории.
- **Dapper** — быстрая и безопасная работа с SQL Server.
- **SOLID** — код соответствует принципам чистой архитектуры.

---

## 🚀 Функциональные возможности

- **Управление компьютерами** — добавление, удаление, просмотр статуса.
- **Управление клиентами** — добавление, отслеживание статуса.
- **Сессии** — начало и завершение сеансов работы за компьютерами.
- **Транзакции** — атомарное обновление данных (сессия → компьютер → клиент).
- **Безопасность** — параметризованные запросы для защиты от SQL-инъекций.
- **Хранение данных** — Microsoft SQL Server (SSMS).

## 🏗️ Архитектура

Проект построен на основе **многослойной архитектуры**:

```
ComputerClub (UI / Console)
    │
    ├── Interfaces (IDBComputers, IDBClients, IDBSessions)
    │       │
    ├── SQLTableComputers (Repository)
    ├── SQLTableClients (Repository)
    └── SQLTableSessions (Repository)
            │
            └── SQL Server (Database)
```

**Принцип работы:**
1. Пользователь взаимодействует с консольным интерфейсом (`ComputerClub`).
2. `ComputerClub` обращается к репозиториям через интерфейсы.
3. Репозитории выполняют запросы к БД через Dapper.
4. Все зависимости передаются через конструктор (DI).
